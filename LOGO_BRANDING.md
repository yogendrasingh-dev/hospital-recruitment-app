## 🎯 Brand Guidelines

### Do's ✅

- Use official color palette
- Maintain clear space around logo
- Keep logo proportions
- Use gradient on light backgrounds
- Ensure good contrast
- Use rounded corners (12-20px)

### Don'ts ❌

- Don't stretch or distort logo
- Don't change colors outside palette
- Don't add effects (shadows, outlines)
- Don't rotate logo
- Don't use low-resolution versions
- Don't place on busy backgrounds

## 🎨 Creating the Logo Assets

### Tools Needed

- Adobe Illustrator / Figma / Sketch
- OR online tools like Canva / Looka

### Steps to Create

1. **Base Shape**
   - Create rounded square (12px radius)
   - Size: 1024x1024px for master file

2. **Add Gradient**
   - Linear gradient top to bottom
   - Colors: #00B4D8 → #0096C7 → #023E8A
   - Angle: 180° (vertical)

3. **Add Text "H+"**
   - Font: Bold sans-serif
   - Size: ~60% of container
   - Color: White (#FFFFFF)
   - Center aligned

4. **Export Sizes**
   - iOS: Use Asset Catalog
   - Android: Use Image Asset Studio

### Quick Alternative

Use the current code implementation which creates text-based logo:

```javascript
// In SplashScreen.js
<View style={styles.logo}>
	<Text style={styles.logoText}>H+</Text>
</View>
```

## 🎬 Animation Guidelines

### Logo Animation

```
Initial State:
  - Scale: 0
  - Opacity: 0

Animation:
  1. Fade In (0.5s)
     Opacity: 0 → 1

  2. Scale Up (0.8s)
     Scale: 0 → 1.2 → 1.0
     Easing: Spring

  3. Hold (1.2s)

  4. Navigate Away
```

### Button Logo

```
Idle:  Scale 1.0
Hover: Scale 1.05
Press: Scale 0.95
```
